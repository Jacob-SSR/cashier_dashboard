# ซอร์สโค้ดจอคิวเดิมของ รพ. (อ้างอิงอย่างเดียว — ไม่ได้ถูก build)

ไฟล์ PHP ในโฟลเดอร์นี้คือของจริงจากจอคิวเดิมที่แขวนอยู่หน้าห้องเก็บเงิน
เก็บไว้เพื่อให้ตรวจสอบได้ว่า `lib/cashier.service.ts` ลอก logic มาถูกต้อง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `moneyAndDrug.php` | หน้าจอหลัก — บอกว่าห้องเก็บเงิน = depcode `013,077,078` และเรียก ajax ทุก 3 วิ |
| `getScreeningW.php` | **คิวรอ** — `ovst` ที่ `cur_dep` อยู่ห้องเก็บเงิน และยังไม่ถูกเรียก |
| `getDoctorRoomQ.php` | **เรียกคิว** ของห้องเก็บเงิน — 2 แถวล่าสุดจาก `sd_queue_calling` |
| `getMedicineQ.php` | เรียกคิวห้องยา (โครงเดียวกัน ต่างที่มี `DATE(...) = CURDATE()`) |
| `getScreeningQ.php` | เรียกคิวจุดคัดกรอง |

สรุปว่าจอเราเอาอะไรมาใช้บ้าง และต่างจากของเดิมตรงไหน: `docs/OPD_FLOW.md`
